Create a reusable Python script named `excel_to_markdown.py` that converts a specific sheet from an Excel workbook into Markdown documentation.

The Excel file may be `.xlsx` or `.xlsb` and can contain multiple sheets with multiple tables per sheet.

The Markdown output will be used by Gemini in VS Code as reference documentation for generating and improving BigQuery SQL test queries.

### 1. Excel support
- Use `python-calamine` to support both `.xlsx` and `.xlsb`.
- Accept the Excel file path as a command-line argument.
- Accept a `--sheet` argument to specify exactly which sheet to process.
- Process ONLY the selected sheet.
- Match the sheet name exactly.
- If the sheet does not exist, display the available sheet names.
- Provide a `--list-sheets` option to display all available sheets without converting them.

### 2. Extract the data
- Read all populated cells in the selected sheet.
- Detect multiple separate tables within the same sheet.
- Identify table headers, section titles, notes, and business rules.
- Preserve the original row and column order.
- Preserve empty cells within tables so column alignment remains correct.
- Preserve multiline text, SQL expressions, source mappings, and filtering conditions.
- Do not summarize, interpret, or change the business logic.
- Do not silently discard any populated cells.

### 3. Generate Markdown
- Create a `specs/` directory if it does not exist.
- Generate one Markdown file for the selected sheet.
- Name the file based on the sheet name, replacing invalid filename characters.
- Use Markdown headings to separate individual tables and sections.
- Convert detected tables into valid Markdown tables.
- Preserve text outside tables as normal Markdown.
- Escape Markdown special characters where required.
- Include the original sheet name and cell ranges for traceability.
- If table boundaries cannot be identified reliably, preserve the content and report the ambiguity instead of guessing.

### 4. Command-line interface

Support these commands:

List sheets:
```bash
python3 excel_to_markdown.py specifications.xlsb --list-sheets
```

Convert one sheet:
```bash
python3 excel_to_markdown.py specifications.xlsb --sheet "CLIENT_FKNS"
```

Convert one sheet to a specific directory:
```bash
python3 excel_to_markdown.py specifications.xlsb --sheet "CLIENT_FKNS" --output specs/
```

### 5. Validation
- Verify that every populated cell from the selected sheet is represented in the Markdown output.
- Report the number of populated cells, detected tables, and generated files.
- Report ambiguous structures or unsupported Excel features.
- Never modify the original workbook.
- Do not overwrite an existing Markdown file unless the user explicitly passes `--overwrite`.

### 6. Deliverables
- Create the working `excel_to_markdown.py` script in my VS Code workspace.
- Create `requirements.txt`.
- Provide short installation and usage instructions for macOS.
- Include error handling for missing files, invalid sheet names, and parsing failures.

Important: The script must work with `.xlsb` files containing multiple sheets, and it must convert ONLY the sheet specified using `--sheet`. Do not generate SQL queries.
